## Positionnement

- **Marque** : RECODE — « the self therapy method » / « la méthode de thérapie personnelle ».
- **Autrice** : Irina Sambucini, coach spécialisée en **neurosciences & Self Therapy**, neuro-thérapeute certifiée + praticienne EFT.
- **Cible** : femmes qui ont « déjà tout essayé par la tête », épuisées, en décalage entre le dehors (« ça va » sur le papier) et le dedans, qui comprennent mais n'avancent pas.
- **Promesse centrale** : retrouver une **stabilité émotionnelle durable** et devenir **la femme sur qui on peut compter** — stable, solide, fiable pour soi-même.

## Idées-force (à réutiliser dans le copy)

- **95 % de tes actions quotidiennes sont pilotées par ton subconscient.** Tu essaies de changer ta vie avec les 5 % restants.
- **« Ce n'est pas toi. C'est ton pilote automatique. »** (ce n'est pas un défaut de caractère, c'est un programme).
- Le cerveau confond **danger et changement** : « Le connu, même douloureux, est rassurant ; l'inconnu, même meilleur, est menaçant. »
- **La tête ne suffit pas — le vrai changement passe par le corps** (système nerveux, EFT), pas par la volonté.
- **Tu n'as pas besoin de plus de motivation.** Tu as besoin d'un système nerveux régulé + de croyances ancrées dans le corps.
- **« Tu n'as pas besoin d'aller mieux pour commencer. Tu as besoin de commencer pour aller mieux. »** Le mouvement crée le mieux-être, pas l'inverse.
- **Plasticité neuronale** : le cerveau se remodèle à tout âge (25, 33, 38, 45, 50+). Il n'est jamais trop tard.
- **Filtre SAR** (Système d'Activation Réticulaire) : le cerveau ne laisse entrer que ce qui confirme ce qu'on croit déjà → reprogrammer le filtre.
- Les **4 F** du système nerveux en survie : Fight, Flight, Freeze, Fawn.
- Les **4 visages du pilote automatique** : perfectionnisme, procrastination, sur-adaptation, hyperactivité/contrôle.

## Le programme (méthode RECODE = 6 modules)

L'acronyme **R-E-C-O-D-E** :

1. **R — Réguler** : réguler le système nerveux saturé, sortir du mode survie. Auto-diagnostic, les 4F, cohérence cardiaque + EFT guidé.
2. **E — Explorer** : identifier ses schémas inconscients répétitifs (relations, travail, image de soi) + session EFT.
3. **C — Connecter** : comprendre le rôle des émotions, les accueillir via la **méthode ARC**, poser ses premières limites + EFT.
4. **O — Ouvrir** : identifier/remplacer les croyances limitantes, reprogrammer le **filtre SAR**, gratitude comme recâblage + EFT.
5. **D — Décider** : installer des habitudes saines (discipline douce), recalibrer la dopamine (réseaux vs ressources naturelles), système perso d'organisation + EFT.
6. **E — Évoluer** : shadow work (réconcilier ses parties intérieures), confiance durable, limites depuis ses valeurs + EFT « femme puissante / higher self ».
